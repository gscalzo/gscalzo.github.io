## The 8-Minute Recipe App

Here's exactly what I did:

**Minute 0-1:** Opened AI Studio, clicked "Build" tab

**Minute 1-2:** Typed this prompt:
```
"Create a recipe discovery app. Users can:
- Browse recipes by cuisine
- Search ingredients
- Save favorites
- Get random recipe suggestions

Design: Clean, modern, mobile-friendly."
```

**Minute 2-5:** Watched Gemini:
- Generate React component structure
- Create API endpoints
- Build database schema
- Design responsive UI
- Add authentication

**Minute 5-7:** Tested the preview
- Found one layout issue
- Said "Make the cards wider on mobile"
- Fixed instantly

**Minute 7-8:** Clicked "Deploy"
- Got a live URL
- Shared with friends

**Result:** A working app, deployed, accessible to anyone.

## How Is This Different From Cursor?

**Cursor:**
- You manage the code
- You handle deployment
- You control everything
- Best for serious development

**AI Studio Build:**
- No code access (unless you export)
- One-click deploy
- Fully managed
- Best for rapid prototyping

It's the difference between **driving** and **taking a taxi**. Sometimes you just want to get there.

## What It Actually Generated

The deployed app included:
- React frontend with Tailwind
- Express backend
- PostgreSQL database
- Google Cloud hosting
- HTTPS out of the box
- Authentication via Google Sign-In

All of this from a 3-sentence prompt.

## The Cost Comparison

**Building a simple web app:**

**Traditional way:**
- 2-3 days development
- £40/month hosting (Vercel/Netlify)
- Manual deployment setup
- Your time and energy

**AI Studio Build:**
- 10 minutes development
- £0-16/month (Google Cloud free tier or pay-as-you-go)
- One-click deployment
- Almost no effort

For prototypes, this is a no-brainer.

## What About Mobile?
