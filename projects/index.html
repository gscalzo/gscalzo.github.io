Projects

These projects are where I test ideas about AI engineering. Some are deliberately small learning tools. Others have had to survive the less glamorous work of becoming a real product.

Nimbo: a coding agent in Swift

An educational coding agent built around a model, a conversation loop, and tools for listing, reading, and editing files. I wrote it to make the mechanics of agents easier to understand.

Read the walkthrough · Explore the source on GitHub

Neurona: from AI prototype to shipped app

A mobile app for iOS and Android, built through experiments with autonomous coding agents. The case study covers the failed native prototype, the move to React Native, and the testing and product work that followed.

The first prototype took a weekend. Shipping took considerably more evenings. I wrote about both.

Read the build story

NSLondon: QR codes and splitting the bill

Two demos from my November 2025 talk: a macOS QR-code generator and an iOS receipt-splitting app. They explore planning, repository instructions, context management, testing, and dividing work between agents.

Watch the talk and read the lessons
